\subsection{Frozen Phase 2 Test Evaluation and Statistical Comparison}
\label{sec:phase2_eval}
Before accessing the untouched TrashNet test split ($N=377$), all three finalists---Phase~1 RBF SVM, fine-tuned MobileNetV2 (\texttt{A2.1}), and equal-weight late fusion (\texttt{H3}, $w=0.5$)---were frozen in \texttt{protocol.json} (git revision \texttt{62db0847}). Each model's scalar temperature $T$ was fitted exclusively on its 1,764 training out-of-fold probabilities, and two abstention thresholds were selected strictly on the 380 validation images: a headline rule ($\ge 90\%$ accuracy, $\ge 80\%$ coverage) and a pre-declared demo rule ($\ge 95\%$ accuracy, $\ge 80\%$ coverage; added because \texttt{H3}'s headline threshold is $0.00$). Model SHA-256 hashes were verified prior to the single test pass.

Table~\ref{tab:phase2_main} reports the single test evaluation. \texttt{H3} Hybrid achieves the strongest test performance across every metric, reaching Macro~F1 $\mathbf{0.9233}$ and accuracy $\mathbf{93.63\%}$ with the lowest expected calibration error ($\mathrm{ECE}=0.0130$, Brier $0.0971$, log loss $0.2257$). At its frozen demo threshold ($\tau=0.53$), \texttt{H3} retains 96.55\% coverage at 95.33\% accepted accuracy, whereas \texttt{A2.1}'s strict demo threshold ($\tau=0.87$) reaches 76.39\% coverage on test, below its 80\% validation target, showing that validation-chosen thresholds do not transfer exactly across splits. Compared against the historical Phase~1 test ensemble (0.8999 Macro~F1, 90.19\% accuracy, ECE 0.1325), the Phase~2 full-train \texttt{phase1\_svm} matches accuracy exactly (90.19\%, Macro~F1 0.8963 vs 0.8999 because the refit SVM uses SVC's internal Platt scaling instead of Phase~1's calibrated ensemble) while OOF temperature scaling reduces test ECE by 72.8\% to 0.0361.

Pairwise exact McNemar binomial tests on discordant unconditional predictions (Table~\ref{tab:phase2_mcnemar}) confirm that \texttt{H3} Hybrid significantly outperforms \texttt{A2.1} CNN ($p=0.00002 < 0.0167$, 23 vs.\ 2 discordant wins, surviving Bonferroni). Although \texttt{H3} leads Phase~1 SVM nominally (23 vs.\ 10, $p=0.0351 < 0.05$), that advantage is suggestive but does not clear the strict Bonferroni threshold $0.0167$ on $N=377$ images (overlapping 95\% bootstrap CIs [0.889, 0.952] vs [0.860, 0.926]); \texttt{A2.1} CNN and Phase~1 SVM do not differ significantly ($p=0.3581$). Hook-based Grad-CAM on \texttt{A2.1}'s final convolutional block across 12 test images (6 correct, 6 errors) gives a qualitative assessment of spatial attention. Foreground is defined heuristically as pixels with HSV saturation $> 0.12$ or value $< 0.92$ (a colour heuristic, without object masks). While 11/12 heatmaps place $\ge 80\%$ of activation mass on the foreground object (mean 93.6\%) rather than TrashNet's white posterboard, Grad-CAM does not explain why \texttt{A2.1} CNN trails Phase~1 SVM ($p=0.358$, not significant), nor does it show complementary spatial features that lift \texttt{H3}; \texttt{H3}'s gain is demonstrated by McNemar discordant counts (23 vs 2 wins, $p=0.000019$), not Grad-CAM. All six inspected errors involve clear object localization on overlapping glass, metal, and plastic shapes and specular reflections. External robustness remains unverified (robustness set not collected), leaving TrashNet background dependence, CV selection optimism, uncommitted working tree during H3 fitting (pinned in protocol.json), and low test support ($n=20$ for trash) as primary limitations.
